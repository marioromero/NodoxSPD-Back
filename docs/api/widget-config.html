API — Configuración del Widget

GET /api/widget/{company_public_uuid}/config Público Sin autenticación

Headers

HeaderRequeridoDescripción
OriginSíOrigen del sitio donde está embebido el widget. Lo valida DynamicCorsMiddleware contra la lista blanca de la empresa.

Parámetros

ParámetroTipoUbicaciónRequeridoDescripción
company_public_uuidUUID v4URLSíIdentificador público de la empresa. Nunca el ID numérico interno.
visitor_uuidUUID v4QueryNoIdentificador del navegador del visitante. Evaluado por el rate limiter por visitante.

Middleware aplicado

MiddlewareFunción
cors.dynamicValida el Origin contra los dominios autorizados de la empresa. Rechaza con 403 si no está en lista blanca.
throttle:widgetRate limiter multicapa: 10 req/min por visitante, 60 req/min por empresa, 5 req/min por IP.

Respuesta exitosa 200

// Respuesta plana, sin objetos anidados company/policy/widget. // Nunca incluye id, company_id ni user_id. { "policy_hash": "a1b2c3d4...", "policy_version": 3, "widget_config": { "position": "bottom-left", "primary_color": "#1a73e8", "show_reject_all": true, "cookie_duration_days": 365, "providers": { "analytics": ["google_analytics", "hotjar"], "marketing": ["meta_pixel", "google_ads"], "personalization": ["intercom"] } }, "purposes": { "necessary": { "label": "Técnicas / Necesarias", "required": true }, "analytics": { "label": "Analítica / Medición", "required": false }, "marketing": { "label": "Publicidad", "required": false }, "personalization": { "label": "Funcionalidad", "required": false } }, "legal_texts": { "banner_title": "Este sitio usa cookies", "banner_body": "Usamos cookies para...", "policy_url": "https://cdn.tudominio.com/policies/a1b2c3d4....html" } }

Campos de la respuesta

CampoTipoDescripción
policy_hashstringSHA-256 del contenido de la política de cookies publicada.
policy_versionintVersión numérica de la política dentro de la empresa.
widget_configobjectConfiguración visual y funcional del widget. Si la empresa no tiene configurada, se devuelven valores por defecto.
purposesobjectMapa de propósitos de cookies. Cada clave (necessary, analytics, marketing, personalization) tiene label (string) y required (bool). necessary es siempre true.
legal_textsobjectTextos legales pre-renderizados para el banner del widget: título, cuerpo y URL de la política completa.

Códigos de error

HTTPCódigoDescripción
400invalid_uuidEl company_public_uuid no es un UUID v4 válido.
403origin_not_allowedEl origen del request no está en la lista blanca de la empresa (DynamicCorsMiddleware).
404no_active_policyLa empresa no tiene una política de cookies publicada.
429Too Many Attempts.Se excedió alguno de los tres límites de tasa (visitante, empresa o IP).
